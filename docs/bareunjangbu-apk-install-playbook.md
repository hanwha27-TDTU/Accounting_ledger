# 바른장부 안드로이드 앱 설치 플레이북

> **v0.69** — 앱 버전과 항상 같은 버전으로 관리됩니다.
>
> ⚠ **이 파일은 자동 생성됩니다 — 직접 고치지 마세요.** 원본은 앱(index.html)의
> "가이드 → 안드로이드 앱 설치" 화면(`androidInstallGuideHtml()`)이고,
> `npm run playbook:build`가 이 파일을 덮어씁니다. 화면과 파일이 어긋나면
> 하네스 REQUIRED 게이트(`install-playbook-sync`)가 실패합니다.

> **안드로이드 휴대폰에만 설치할 수 있습니다.** 아이폰(iOS)은 지원하지 않습니다. 이 링크는 항상 최신 버전을 가리켜서, 새로 눌러 받을 때마다 최신 앱이 설치됩니다(대부분의 경우 재설치 없이 웹 내용은 앱을 열 때마다 자동으로 최신 상태로 바뀝니다).

> 휴대폰의 인터넷(크롬 등) 브라우저로 이 페이지를 열고 아래 버튼을 누르세요.

➡ [바른장부 APK 내려받기](https://github.com/hanwha27-TDTU/Accounting_ledger/releases/download/apk-latest/bareunjangbu-latest.apk)

- **다운로드 주소**: `https://github.com/hanwha27-TDTU/Accounting_ledger/releases/download/apk-latest/bareunjangbu-latest.apk`

## 2. "차단된 파일" 또는 "알 수 없는 출처" 경고가 뜨면

> 안드로이드가 새로운 앱을 설치할 때 항상 보여주는 안내입니다 — 겁먹지 않아도 됩니다.

1. 다운로드 알림을 눌렀을 때 **"이 파일 형식은 이 기기에서 지원되지 않습니다"** 또는 **"차단된 파일"**이 뜨면, 화면의 **설정**을 누릅니다.
2. **"알 수 없는 앱 설치"** 또는 **"출처를 알 수 없는 앱"** 항목에서 지금 쓰는 브라우저(크롬 등)를 찾아 **허용**으로 켭니다.
3. 뒤로 돌아가 방금 받은 파일을 다시 누릅니다.
4. 이번엔 정상적으로 설치 화면이 뜹니다 — **설치**를 누릅니다.

> 이 경고는 "구글 플레이스토어를 거치지 않은 앱"이라는 뜻일 뿐, 위험하다는 뜻이 아닙니다. 이 앱은 오픈소스 저장소(GitHub)에서 자동으로 만들어져 배포됩니다.

## 3. 설치 후 실행하고 로그인합니다

> 앱을 열면 평소 웹에서 쓰던 것과 완전히 같은 화면이 나옵니다.

1. 홈 화면이나 앱 서랍에서 **바른장부** 아이콘을 눌러 엽니다.
2. 왼쪽 메뉴에서 **설정**으로 이동해 평소처럼 **Google로 로그인**을 누릅니다.
3. 구글 로그인 화면은 앱 안이 아니라 별도 브라우저 창으로 열립니다(구글이 보안상 앱 내부 로그인을 막기 때문입니다) — 로그인을 마치면 자동으로 앱으로 돌아옵니다.
4. 돌아온 뒤 위쪽 상태가 **동기화 완료**이면 끝입니다.

## 4. 업데이트는 대부분 저절로 됩니다

> 두 가지 갱신이 있어요 — 하나는 완전 자동, 하나는 탭 한 번만 필요해요.

> **① 화면·기능 갱신 — 완전 자동, 할 일 없음.**
> 계산기나 새 기능처럼 눈에 보이는 내용이 바뀌면 앱을 열거나 다른 화면으로 넘어갈 때 저절로 최신 내용으로 바뀝니다. 아무것도 누를 필요가 없습니다.

> **② 앱 자체 갱신 — 배너가 알려주고, 버튼 한 번 + 설치 확인 한 번이면 끝.**
> 로그인 방식이나 권한처럼 앱 안쪽 구조가 바뀌면, 앱을 열 때 화면 아래에 **"새 버전 앱이 나왔어요"** 배너가 뜹니다. 배너의 **업데이트** 버튼을 누르면 다운로드가 시작되고, 끝나면 안드로이드가 "설치하시겠습니까?" 화면을 보여주는데, 이건 안드로이드가 모든 앱에 강제하는 보안 확인이라 앱이 대신 눌러줄 수 없습니다 — **이때 한 번만 "설치"를 눌러주면** 갱신이 끝납니다. 지금 바쁘면 배너의 X를 눌러 닫아도 되고, 설치하기 전까지는 앱을 열 때마다 다시 알려드립니다.

혹시 이 자동 확인을 놓쳤거나 지금 바로 최신 버전인지 확인하고 싶으면, 이 페이지에서 위 1단계 버튼을 다시 눌러 받으면 됩니다. 링크 주소는 항상 똑같아서(`apk-latest`), 즐겨찾기해두면 매번 최신 버전을 받을 수 있습니다.
